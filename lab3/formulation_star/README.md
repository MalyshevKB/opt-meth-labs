# Две MILP-формулировки плана ремонтов

Задание со звёздочкой для ЛР №3, вариант 16. Код сравнивает исходную модель с формулировкой, которая раздельно ограничивает нагрузку при вызове подрядчика и при работе собственной бригадой. [Постановка, доказательство и результаты](REPORT.md)

Из папки `lab3` с установленными зависимостями запустите

```powershell
.venv/Scripts/python.exe -m formulation_star.run
```

Скрипт генерирует экземпляры на 10, 20, 40 и 80 единиц по seed 10215. Сводная таблица и логи каждого решения записываются в `formulation_star/results/`.
