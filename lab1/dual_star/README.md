# Двойственная задача для ЛР №1

Задание со звёздочкой для варианта 16. Модель использует исходные CSV ЛР №1 и её зависимости. Постановка, численная сверка и интерпретация приведены в [пояснении](REPORT.md).

Из папки `lab1` с установленными зависимостями запустите в PowerShell

```powershell
.venv/Scripts/python.exe -m dual_star.run
```

При активном окружении подойдёт `python -m dual_star.run`. Скрипт обновляет таблицы проверки и логи HiGHS в `dual_star/results`.
