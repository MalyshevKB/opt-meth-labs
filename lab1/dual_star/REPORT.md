# Задание со звёздочкой. Двойственная задача для ЛР №1

Вариант 16, группа 527, seed 10215. Исходная задача минимизирует суточную стоимость кормления трёх видов животных десятью кормами. Используются данные и обозначения [основного отчёта](../REPORT.md).

## Постановка

Пусть $x_{af}\ge 0$ — кг корма $f$ на голову вида $a$ в сутки. Стоимость в расчёте на весь зоопарк равна $\sum_{a,f} n_a c_f x_{af}$. Запишем все конечные границы в виде $Gx\ge b$. Нижние нормы сохраняют знак, верхние границы меняют знак. При наличии обеих границ появляются две строки. У каждого запрещённого сочетания добавляется строка $-x_{af}\ge0$, поэтому в модели сохранены все 30 переменных рациона.

Каждой строке соответствует неотрицательный множитель.

| Множитель | Строка прямой задачи до смены знака |
|---|---|
| $\lambda^-_{ak},\lambda^+_{ak}$ | Нижняя и верхняя нормы нутриента $k$ |
| $\mu_a$ | Максимальная масса рациона $M_a$ |
| $\gamma_{ag}$ | Максимальная доля допустимого корма $g$ |
| $\alpha_a,\beta_a$ | Минимальная и максимальная доля животных кормов |
| $\sigma_f$ | Суточный запас $S_f$ |
| $\eta_{af}$ | Верхняя граница $x_{af}\le0$ для запрещённого корма |

Множитель для отсутствующей границы считается нулевым. Пусть $q_f$ — индикатор корма животного происхождения, $s_a$ — максимальная доля отдельного корма, $p_a^{min}$ и $p_a^{max}$ — границы доли животных кормов. Полная двойственная задача имеет 64 переменные и 30 ограничений.

$$
\max\quad \sum_{a,k}\left(L_{ak}\lambda^-_{ak}-U_{ak}\lambda^+_{ak}\right)
-\sum_a M_a\mu_a-\sum_f S_f\sigma_f .
$$

Суммы по нормам включают только заданные границы. У ограничений на доли и совместимость правая часть равна нулю, поэтому их множители входят только в ограничения двойственной задачи. Для каждой пары $(a,f)$ требуется

$$
\begin{aligned}
 &\sum_k a_{fk}(\lambda^-_{ak}-\lambda^+_{ak})
 -\mu_a-\gamma_{af}+s_a\sum_g\gamma_{ag} \\
 &\quad +(q_f-p_a^{min})\alpha_a-(q_f-p_a^{max})\beta_a
 -n_a\sigma_f-\eta_{af}
 \le n_a c_f .
\end{aligned}
$$

В матричной форме это $\max b^Ty$ при $G^Ty\le c$ и $y\ge0$, где вектор $c$ содержит коэффициенты $n_a c_f$. Для любых допустимых $x,y$ выполнено $b^Ty\le y^TGx\le c^Tx$. Совпадение целей даёт сертификат оптимальности обеих точек.

## Решение и проверка

HiGHS решает две отдельно построенные модели. Для двойственной задачи скрипт минимизирует $-b^Ty$ и возвращает знак цели при сравнении. NumPy пересчитывает цели, проверяет допустимость обеих точек и дополняющую нежёсткость $y_i(Gx-b)_i=0$, $x_j(c-G^Ty)_j=0$.

| Показатель | Результат |
|---|---:|
| Минимум прямой задачи, ₽/сут | 2 421,8627026081 |
| Максимум двойственной задачи, ₽/сут | 2 421,8627026081 |
| Абсолютный разрыв целей, ₽/сут | 0 |
| Наибольшая невязка среди девяти проверок | $2{,}02\cdot10^{-13}$ |

Все девять проверок проходят с абсолютным допуском $10^{-7}$. Полные векторы и невязки приведены в файлах [множителей](results/multipliers.csv), [двойственных ограничений](results/dual_constraints.csv) и [проверок](results/checks.csv).

## Экономический смысл множителей

- **Запас люцерны.** $\sigma_f=17{,}45726$. Увеличение верхней границы запаса уменьшает минимальные затраты на 17,46 ₽/сут за дополнительный кг/сут в окрестности текущего значения. При увеличении с 19,31 до 20,31 кг/сут прогноз равен −17,4572609653 ₽/сут. Повторное решение дало ту же величину с погрешностью около $6\cdot10^{-13}$ ₽/сут. [Таблица эксперимента](results/supply_plus_one.csv)
- **Нижние нормы.** Дополнительный грамм клетчатки в суточной норме одной зебры повышает стоимость рациона всего зоопарка примерно на 0,65 ₽/сут. Для шимпанзе соответствующая оценка составляет 2,52 ₽/сут, для грамма протеина в норме бурого медведя — 1,48 ₽/сут. Тем же множителям соответствует снижение затрат при небольшом ослаблении норм.
- **Вместимость, доли и совместимость.** $\mu_a$ и $\sigma_f$ оценивают ослабление верхних границ массы и запасов. $\gamma_{ag}$, $\alpha_a$ и $\beta_a$ оценивают предельное изменение правой части линеаризованных ограничений на доли. Для оценки изменения самой доли в процентных пунктах нужно учитывать массу рациона, поскольку меняется коэффициент при переменных. $\eta_{af}$ относится к локальному ослаблению нулевой границы при фиксированных остальных строках. Число для запрещённого корма может зависеть от выбора двойственного оптимума, поскольку переменная зафиксирована одновременно снизу и сверху. Полное разрешение корма требует пересмотра модели, включая ограничение разнообразия.

В столбце `rhs_sensitivity` записан множитель со знаком исходной границы. Для нижних границ знак положительный, для верхних отрицательный, если множитель ненулевой. Эти оценки локальны.
