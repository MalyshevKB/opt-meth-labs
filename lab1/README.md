# ЛР №1. ЛП-модель распределения ресурсов — вариант 16

**Рацион кормления в зоопарке с требованием разнообразия** (10 кормов, 5 норм, 3 вида животных).
Группа 527 (Q = 2), N = 15, Y = 26 → V = 1 + ((17·15 + 7·2 + 26) mod 20) = 16, seed = 10215.

Отчёт: [REPORT.md](REPORT.md).

## Установка

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
```

(на Linux/macOS: `.venv/bin/python`). Проверено на Python 3.14.7, HiGHS 1.15.1 (`highspy`).

## Запуск

Одна команда: генерирует данные с фиксированным seed, решает все сценарии, проверяет решения и строит графики.

```bash
.venv/Scripts/python run.py
```

Пример вывода:

```
Вариант 16, seed 10215. Статус: Optimal, стоимость рациона 2421.86 ₽/сут, итераций симплекса 11
Независимая проверка: 95 условий, все выполнены: True
Ключевой ресурс по теневой цене: Люцерна (сено)
```

## Структура

| Путь | Назначение |
|---|---|
| `zoo_lp/data_gen.py` | генерация данных варианта (опорные значения + шум с seed 10215) |
| `zoo_lp/model.py` | загрузка данных, построение модели, решение HiGHS, эластичная модель, поиск IIS |
| `zoo_lp/verify.py` | независимая проверка допустимости и цели (NumPy/pandas, без объекта солвера) |
| `run.py` | сценарии, теневые цены, параметрический анализ, сравнение алгоритмов, графики |
| `data/` | `feeds.csv`, `animals.csv`, `norms.csv`, `compat.csv`, `meta.json` |
| `results/` | логи солвера `highs_*.log`, решения и проверки (CSV), сценарии, графики (PNG) |

Основные результаты в `results/`:

- `solution_base.csv` — оптимальный рацион (кг/гол/сут, кг/сут, ₽/сут);
- `check_base.csv` — независимая проверка всех 95 условий;
- `scenarios.csv`, `ration_by_scenario.csv` — сценарный анализ;
- `shadow_prices.csv`, `cost_ranging.csv` — теневые цены, приведённые стоимости, диапазоны устойчивости;
- `iis_stress2.csv`, `elastic_stress2.csv` — диагностика несовместного сценария;
- `parametric_key_supply.csv` — фактический оптимум и прогноз по теневой цене;
- `solver_comparison.csv` — симплекс и метод внутренней точки.
